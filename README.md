# Dashly 🚀

Modern focus & habit tracking dashboard built with **React + Vite + Tailwind CSS**.

## ✨ Features

- 📊 Full-screen dashboard layout (no margins)
- ⏱️ Focus Timer (Pomodoro-style 25min sessions)
- 📅 Habit Tracker with progress bars
- 📈 Weekly progress charts
- 🤖 AI Coach chat interface
- ✅ Task management
- 🎨 Responsive design (mobile + desktop)

## 🛠️ Tech Stack

Frontend: React 18 + Vite + Tailwind CSS
Routing: React Router DOM
State: React Hooks (useState, useEffect)
Styling: Tailwind CSS (pure, no Bootstrap)

## 🚀 Quick Start

Clone & install
git clone <https://github.com/syad0987/Focusflow-dashboard->
cd Dashly
npm install

Development
npm run dev

Build
npm run build

## 📁 Project Structure

src/
├── components/ # Reusable UI: Sidebar, Topbar, FocusTimer, etc.
├── pages/ # Routed pages: Dashboard, Focus_mode, Habit_tracker
├── App.jsx # Main router + Layout
└── main.jsx # Entry point
